# KemaFinance

Sistema de gestao financeira pessoal com dashboard inteligente, categorizacao automatizada e consultoria via inteligencia artificial.

## Funcionalidades

- Dashboard com score financeiro 0-100 baseado em receitas, despesas, dividas e investimentos
- Categorizacao inteligente de transacoes
- Metas financeiras metodo 50-30-20
- Relatorios exportaveis em CSV e PDF
- Consultoria financeira via Gemini AI
- PWA com suporte offline parcial

## Stack

React, TypeScript, Supabase, shadcn/ui, Gemini AI, Vite, PWA
